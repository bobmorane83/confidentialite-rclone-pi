# confidentialite-rclone-pi

Politique de confidentialité publique de l'application OAuth `rclone-pi-backup`
(client Google personnel utilisé pour sauvegarder un Raspberry Pi vers Google Drive).

Page publiée : https://bobmorane83.github.io/confidentialite-rclone-pi/

Ce dépôt ne contient qu'un document statique, publié via GitHub Pages pour fournir
l'URL de règles de confidentialité exigée par Google Auth Platform.
