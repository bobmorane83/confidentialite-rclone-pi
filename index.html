Politique de confidentialité — application rclone-pi-backup

Dernière mise à jour : 1er novembre 2026.

Cette page décrit le traitement des données par l'application OAuth rclone-pi-backup, un client Google que son unique utilisateur installe sur son propre Raspberry Pi pour sauvegarder ses serveurs personnels vers son propre espace Google Drive.

Responsable

Vincent Pillet — contact : bmorane83@gmail.com.

Données auxquelles l'application accède

L'application demande un unique accès à l'API Google Drive (https://www.googleapis.com/auth/drive), utilisé exclusivement par les scripts de sauvegarde exécutés sur le Raspberry Pi de l'utilisateur, pour :

  • déposer des archives de sauvegarde dans des dossiers Google Drive de l'utilisateur (base de données Home Assistant, base de données TeslaMate, configuration de routeur) ;
  • lister et supprimer les archives de ces mêmes dossiers afin d'appliquer la rétention (les dumps les plus anciens sont purgés).

Aucune autre donnée n'est demandée : ni Gmail, ni Contacts, ni Agenda, ni profil.

Ce que l'application ne fait pas

  • Aucun transfert de données à un tiers : les fichiers restent dans le Drive de l'utilisateur.
  • Aucune publicité, aucun profilage, aucune revente de données.
  • Aucun serveur intermédiaire : le Pi dialogue directement avec l'API Google.

Stockage et durée de conservation

Les jetons d'accès OAuth sont stockés uniquement sur le Raspberry Pi de l'utilisateur, dans des fichiers en lecture restreinte au compte système qui exécute les sauvegardes. Les archives conservées dans Google Drive suivent la politique de rétention configurée localement (par exemple : 2 dumps quotidiens conservés en ligne, puis suppression automatique).

Vos droits et la révocation

L'accès peut être retiré à tout moment depuis la page Applications tierces ayant accès à votre compte, ou en supprimant les jetons sur l'appareil. La révocation interrompt immédiatement toute nouvelle opération.

Modifications

Toute évolution de cette politique sera publiée sur cette page, avec la date de mise à jour correspondante.
